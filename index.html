Графики Fakⱼ(t)

Шесть внешних факторов во времени; форма кривых повторяет предоставленный пример.

Fak₁ — опыт разработчиков; Fak₂ — опыт эксплуатационного персонала; Fak₃ — трудоёмкость разработки; Fak₄ — нормированный курс рубля к доллару; Fak₅ — деловая репутация разработчиков; Fak₆ — репутация организации-эксплуатанта. Профили нормированы по времени от 0 до T и используются в правых частях уравнений. В настройках можно переключить отдельный фактор на постоянный, линейный или синусоидальный закон.

Характеристики системы по четвертям

Синяя линия — u(0), красная — u(t). Все пять диаграмм используют одну шкалу без обрезки значений. Числа на осях — значения u, подписи по кругу — номера показателей.

    Синусоида: base + A · sin(2πt/P + φ). Линейный закон: base + A · t. Все значения Fak на интервале должны оставаться в [0; 1].     Проверка выполнимости плана операций

    Приложение воспроизводит систему из файла «2_laba.docx»: 25 дифференциальных уравнений, 101 функция связи, шесть настраиваемых факторов. Базовые слагаемые исходных уравнений сохранены; прямое влияние всех шести факторов добавлено по знаковой матрице связей. Показатели u₁, u₇, u₈, u₉, u₁₀ и u₁₁ описывают качество; остальные 19 — дефекты.

    Что принято для расчёта

    В исходнике не заданы коэффициенты функций, начальные состояния, нормирующие значения и пороги. Их можно изменить. u₅₄ принят внешней постоянной, поскольку для него нет уравнения. Матрица задаёт знак прямого влияния каждого Fak на каждую переменную. Коэффициент 0,1 в факторных слагаемых является калибровочным допущением, а не значением из исходной матрицы.

    Численный метод

    Классический метод Рунге — Кутты 4-го порядка. На каждом шаге используются четыре оценки производной. Для контроля конечного результата выполняется второй прогон с h/2. Показана оценка |uₕ(T) − uₕ/₂(T)| / 15 по максимальной компоненте. Это индикатор сходимости, а не строгая гарантия ошибки.

    Критерий выполнимости

    В момент T все шесть характеристик должны достигать нижних порогов, а 19 дефектов — не превышать верхние пороги. Дополнительно вся рассчитанная траектория должна оставаться в [0; 1]. Первое одновременное выполнение порогов определяется по узлам сетки. Результат относится только к заданным параметрам.

    Сохранение работы

    Проект JSON содержит все исходные параметры. CSV содержит все 25 траекторий. Последние настройки сохраняются локально в браузере при расчёте. Приложение не отправляет расчёты на сервер.
